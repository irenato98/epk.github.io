RENATO BIBOLOTTI ARCHIVES

Sitio estático responsive listo para GitHub Pages. No requiere instalación ni comando de build.

Rutas:
- https://rboarchives.com/
- https://rboarchives.com/drummercareer/
- https://rboarchives.com/contact/

Breakpoint responsive:
- Hasta 1024 px: estructura vertical 9:16.
- Desde 1025 px: estructura panorámica 16:9.

Publicación:
1. Descomprime el ZIP.
2. Sube todos los archivos y carpetas a la raíz del repositorio.
3. Reemplaza los archivos existentes y conserva la estructura.
4. Publica la rama principal desde GitHub Pages.
